# MoneyKeeper

**A Simple Personal Finance Manager built in C.**

MoneyKeeper is a personal finance management application developed in C as a learning project. Its goal is to provide a simple way to record income and expenses, track transactions, and calculate the current balance.

## Features

- Register income.
- Register expenses.
- Store transaction details:
  - ID
  - Description
  - Amount
  - Date
  - Type
- Calculate the current balance.
- View financial information through a console interface.

## Running the Project

Compile with GCC:

```bash
gcc main.c -o MoneyKeeper
```

Run on Windows:

```powershell
.\MoneyKeeper.exe
```
